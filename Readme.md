## 📌 Overview

This project simulates a real-world **Security Assessment** conducted for a large-scale cryptocurrency platform. As the **Lead Security Engineer**, I conducted an end-to-end evaluation of vulnerabilities in the application stack, containerized services, and exposed APIs. This report outlines both **technical implementations** and **strategic risk analysis**.

---

## 🎯 Objectives

- Integrate security into SDLC stages  
- Assess and remediate login system vulnerabilities  
- Run container vulnerability scans using **Trivy**  
- Identify & mitigate API vulnerabilities  
- Build a threat matrix and remediation plans
